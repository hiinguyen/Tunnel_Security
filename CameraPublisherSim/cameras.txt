# Danh sách camera giả lập — mỗi dòng 1 camera, dạng:
#   cameraId=đường_dẫn_hoặc_link_video
#   cameraId=đường_dẫn_hoặc_link_video,fps   (fps tùy chọn, mặc định lấy từ CAMERA_FPS hoặc 24)
#
# - cameraId phải khớp với Camera.Id mà BackendV2 tạo khi node tham gia: CAM-L{tuyến}-N{số node}
#   (tuyến k = Lines.Id do backend cấp, node n = hố ga thứ n của tuyến theo Station/Assets/Map/nodes.json)
#   Hiện tại: tuyến 2 = Đội Cấn (DC), 3 = Kim Mã (KM), 4 = Phan Đình Phùng (PDP), 5 = Hoàng Hoa Thám (HHT)
#   (tuyến 1 là tuyến dev nm-dev-1, không có camera). ID sai thì publisher vẫn chạy nhưng viewer không thấy hình.
#   Kiểm tra: SELECT Id FROM Cameras trong DB TunnelSecurityV2.
# - Giá trị sau dấu "=" có thể là đường dẫn file local (D:\Videos\a.mp4)
#   hoặc link mạng mà ffmpeg đọc được (http/https/rtsp/rtmp)
# - Dòng bắt đầu bằng "#" hoặc để trống sẽ bị bỏ qua
#
# Ví dụ:
# CAM-HUB-01=D:\Videos\camera1.mp4
# CAM-HUB-02=D:\Videos\camera2.mp4,10
# CAM-HUB-03=https://example.com/stream.mp4
